打型號（UX-21）就會列出全台有這支的門市；打門市名（忠孝）就只看那間。

商品型號

清單內容 = 「抽選連結」分頁目前的篩選結果。先在那邊挑好縣市／型號，再回來這裡複製或下載。

抽選前要先加該門市的 LINE 官方帳號好友，否則點抽獎連結會進不去。這裡是各門市帳號，點過會變灰。

這頁只是把連結整理好，抽選還是要你自己在 LINE 裡面照規則手動完成。 本頁不會、也不能幫你自動抽或提高中獎率。

怎麼用（手機）

  1. 先到「加好友」把你會去的門市官方帳號加起來。
  2. 回「抽選連結」，用搜尋或型號按鈕挑出你要的（例如 UX-21）。
  3. 點綠色的「抽選」→ 會跳出 LINE，在裡面完成抽選。
  4. 抽完回來，那一列會自己變灰。沒變灰的話按右邊的 ✓ 手動標記。
  5. 勾「只看今天還沒抽的」，剩下的就是你還沒點過的。

已抽記錄怎麼算

  • 記錄存在這台裝置的瀏覽器裡（localStorage），不會上傳，換手機或清瀏覽資料就沒了。
  • 以日期為單位：今天標過的顯示灰色劃線；前幾天抽過的會標示「前次 X/XX」但仍算可抽，因為每天是新一輪。
  • 用門市＋商品當記錄鍵，所以官方換連結網址也不會弄丟你今天的記錄。

資料更新

  • 抽選連結每天／每期都會換。本頁資料是靜態的，需要重新產生。
  • 在電腦上執行 update.bat（或 python extract.py 再 python build.py）就會抓最新連結並重新產生這個頁面。
